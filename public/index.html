Trakt 增强

Loon 插件：让 Trakt App 显示中文标题、简介和海报（简体 / 港台繁体），并在影片详情页添加 EplayerX、Forward、Infuse、Rex 跳转按钮。

添加到 Loon GitHub

功能

  • 中文标题、简介和海报 剧集、电影、单集、评论、片单和演职员表显示中文，海报换成 TMDb 中文海报；可选简体、台湾繁体、香港繁体。
  • 只翻译中文影视 默认只翻译原始语言为中文的剧集和电影，其他语言保留 Trakt 原文；可在插件设置里关闭。
  • 中文影视用中文原海报 中文剧集和电影用原产地区的中文海报（台剧用台版、港片用港版），其他影视按「海报语言」。
  • 人物页和人物搜索翻译 人物详情页可单独开关；人物搜索可选全部翻译、只翻译华人和日韩名、只翻译华人名或关闭。
  • 播放器跳转按钮 影片详情页添加 EplayerX、Forward、Infuse、Rex 按钮，顺序和显示可在插件设置里调整。
  • 历史记录按剧集合并 历史页面剧集类别的已观看记录按电视剧合并显示。

安装

  1. 在装有 Loon 的设备上点「添加到 Loon」，或复制插件地址后在 Loon 的「插件」里手动添加。
  2. 确认 Loon 已开启 MitM，并已安装和信任证书。
  3. 打开 Trakt App 使用即可。插件选项在 Loon 的插件详情里设置。

关于本站

本站是插件使用的翻译缓存后端，保存翻译、海报和人物名的缓存，只响应插件发出的请求。

缓存和 TMDb 数据仅供个人使用。

脚本基于 DemoJameson/Proxy.Modules 2026-10-28 版本（MIT 许可）修改。
